# Knowledge Base Versioning Process

## Rules
1. Every KB change must update the `app/rag/knowledge_base/kb_chunks.json` file.
2. Every update must be logged in `app/rag/CHANGELOG.md`.
3. Version format: `v1`, `v2`, `v3`...
4. Only the Team Lead can approve a new KB version.

## Traceability
- **Who approved:** Team Lead (Ujala)
- **Current Version:** v1 (Original)
